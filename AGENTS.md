# ScaleOps development contract
Build a serious recruiter-facing programme operations prototype; use calm, editorial, information-dense working surfaces rather than generic KPI dashboards. Four connected workflows: Cohort Control, Admissions Flow, Participant Ops, Operations Brief. Every action must update dependent views and a visible audit trail. All records are synthetic, never LASR internal data.

Keep rules in the deterministic, independently testable OpsEngine. Use explicit thresholds, typed entities, and a replaceable data repository. No credentials required for V1. Local persistence must validate stored data and offer reset. Sensitive admissions decisions, welfare, visa eligibility, legal questions and policy exceptions require human handling. Never infer protected attributes or silently score candidates. Reminder drafts are templates for human review; never claim model inference or message delivery when absent.

Use the existing isolated checkout; do not create worktrees unless requested. Continue ordinary engineering work autonomously. Preserve user changes. Document tradeoffs and maintain BUILD_STATUS.md. Run lint, typecheck, unit/integration tests, production build and meaningful Playwright journeys. Do not weaken tests to conceal defects. Provide accessible controls, keyboard command palette, visible focus, reduced motion and useful responsive behavior.
